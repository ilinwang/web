1st coding assignment
Due 2025/09/23 09:00

You are asked to write a program which can

  • Step 1: read a nonnegative integer number n that is larger than 4
    (e.g. keyin "5")
  • Step 2: ask the user to input these n integers
    (separated by space, e.g. keyin "2 4 -1 5 6")
  • Step 3.1: if n is larger than 4, then print out these n numbers one by one and report their
    • min, 2nd min (i.e. the 2nd smallest), max, 2nd max (i.e. the 2nd largest), sum, and product
  • Step 3.2: if n is smaller than or equal to 4, then print out warning message and ask the user to input an integer at least 5, and GOTO Step 2
  • for example, the correct output may look like the following

Among the 5 integers: 2 4 -1 5 6
min= -1 ; 2nd_min= 2 ; max= 6 ; 2nd_max= 5; sum= 16 ; product= -240

example: suppose your code is named as sf1, then when you execute sf1 in command line (e.g. keyin " ./sf1"), you should see:

Please input a positive integer n larger than 4: (then you may input, say, 3, then press enter)

then you should see the following message on the screen, say,

!!Warning!! 3 is NOT larger than 4!
Please input a positive integer n larger than 4: (then you may input, say, 5, then press enter)

then you should see the following message on the screen, say,

Please input 5 integers: (then you input, say, 2 4 -1 5 6, then press enter)

Finally, your code should print out

Among the 5 integers: 2 4 -1 5 6
min= -1 ; 2nd_min= 2 ; max= 6 ; 2nd_max= 5; sum= 16 ; product= -240

!!Special notice!!:

  1. Since you do not know how large n is, you should dynamically allocate memory for a give n. In other words, if you set n as a very large fixed number, you will receive minus points!!
  2. You DO NOT HAVE TO take care of any other invalid input (e.g. if someone input a real number, or a character/string, your code does not need to detect these invalid input, even if the output is invalid.)
  3. Whatever compiler you use, you must make sure your code can be compiled and run in unix environment (i.e. cygwin or SUN).
  4. Your code HAS TO follow the instruction as requested in programming.html. More specifically, you should try to follow the instruction to write the comments in the very beginning of your code.
  5. You have to submit your code electronically to our moodle website in time (0900 am).
